# 孙晓伟 · 个人作品集

React + Vite 单页作品集，PC 版心最大 1700px，同时提供平板和手机布局。

## 本地运行

需要 Node.js 20.19+ 或 22.12+，以及 pnpm。

```sh
pnpm install
pnpm dev
```

打开 http://127.0.0.1:5173/ 。

```sh
pnpm build
pnpm preview
```

生产文件输出到 `dist/`，可以部署到任意静态网站托管平台。

## 内容与素材

- `src/content.js`：个人信息、项目、经历、能力文案。
- `src/more-projects.js`：完整语雀作品集补充的三维、CG、AI 视觉、IP 与品牌项目，保留来源卡片编号用于核对。
- `src/main.jsx`：五个页面模块、视频弹窗和交互。
- `src/styles.css`：颜色、字体、版心、各尺寸布局。
- `public/assets/`：本站使用的作品视频、封面、简历和字体。
- `.openai/hosting.json`：当前私人预览站点的部署配置。

素材来自用户提供的简历、本地作品文件夹及本人语雀作品集。视频转换为浏览器通用的 H.264/AAC，封面取自实际视频帧；不依赖语雀临时签名的视频地址。背景视频约 4MB，其余成片只在打开作品弹窗时加载。字体已随源码附带，授权说明保存在字体目录中。

「大疆」与「大疆 Osmo 360 II」是两个独立项目。`D:/2026AI作品集/大疆` 的七段素材归入无人机项目，包含雪山转场、开场镜头、两组 C4D 白膜预演与 AI 生成，以及 AE 后期。「大疆360」文件夹对应 Osmo 360 II，展示成片片段和 C4D 白膜预演，发布链接为 https://www.bilibili.com/video/BV1NSgp6vEEV/ 。「打印机」文件夹归入拓竹 A1 项目，按用户指定的 00—06 顺序接入七段素材，发布链接为 https://www.bilibili.com/video/BV19Z4b6gE7f/ 。「莲花汽车项目」包含品牌开场、人物登场、模型雕刻、座舱、车友互动及车友合影六段素材；后三段按用户确认标注为实拍与 AI 角色融合，附带原尺寸人物三视图与面部特写，发布链接为 https://www.bilibili.com/video/BV1Untc6RETm/ 。各链接按用户提供的项目归属对应，本网站展示本人制作的相关片段。手机支架项目为三维制作；两条 AI 叙事短片标为个人创作。账号数据来自此前提供的历史截图，不代表实时数据。经历日期与下载简历按提供的 `D:/2026AI作品集/孙晓伟简历.pdf` 整理。

## 已提供的交互

- 首页背景视频播放与暂停；减少动态效果偏好会阻止自动播放。
- 锚点导航、移动端菜单、项目分类筛选。
- 项目弹窗、上一个/下一个、Esc 关闭与焦点返回，数量按项目内容自动统计；支持视频、设计图和 GIF 动图。
- 所有作品视频保留原生播放、进度条点击/拖动、音量和全屏控制，新增快退/快进 5 秒及 0.25—2 倍速；同一项目切换片段时保留倍速。
- 全部作品、商业视频、三维 / CG、个人创作筛选。
- 大疆项目的同一镜头合并为单个缩略图，旧款变新款、无人机讲解及 Osmo 360 II 可在视频右上角切换「白膜预演 / AI 生成」，默认展示 AI 版本。每个视频按需加载。
- 拓竹 A1 按 00—06 顺序展示七段视频，播放结束自动接下一段，最后一段结束后停止。
- 莲花汽车六段视频切换，展示人物三视图与面部特写，支持查看原图。
- 经历展开、简历下载、电话和邮箱复制、邮件联系链接。
