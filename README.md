# 孙晓伟 · 个人作品集

React + Vite 单页作品集，PC 版心最大 1700px，同时提供平板和手机布局。

## 本地运行

需要 Node.js 20.19+ 或 22.12+，以及 pnpm。

```sh
pnpm install
pnpm dev
```

打开 http://127.0.0.1:5173/ 。

```sh
pnpm build
pnpm preview
```

生产文件输出到 `dist/`，可以部署到任意静态网站托管平台。

## 内容与素材

- `src/content.js`：个人信息、项目、经历、能力文案。
- `src/main.jsx`：五个页面模块、视频弹窗和交互。
- `src/styles.css`：颜色、字体、版心、各尺寸布局。
- `public/assets/`：本站使用的作品视频、封面、简历和字体。
- `.openai/hosting.json`：当前私人预览站点的部署配置。

素材来自用户提供的简历、本地作品文件夹及本人语雀作品集。视频转换为浏览器通用的 H.264/AAC，封面取自实际视频帧；不依赖语雀临时签名的视频地址。背景视频约 4MB，其余成片只在打开作品弹窗时加载。字体已随源码附带，授权说明保存在字体目录中。

「大疆」与「大疆 Osmo 360 II」是两个独立项目。`D:/2026AI作品集/大疆` 的七段素材归入无人机项目，包含雪山转场、开场镜头、两组 C4D 白膜预演与 AI 生成，以及 AE 后期。「大疆360」文件夹对应 Osmo 360 II，展示成片片段和 C4D 白膜预演，发布链接为 https://www.bilibili.com/video/BV1NSgp6vEEV/ 。「打印机」文件夹归入拓竹 A1 项目，接入八段素材，发布链接为 https://www.bilibili.com/video/BV19Z4b6gE7f/ 。「莲花汽车项目」选用品牌开场、人物登场、模型雕刻、座舱及车友场景五段素材，发布链接为 https://www.bilibili.com/video/BV1Untc6RETm/ 。各链接按用户提供的项目归属对应，本网站展示本人制作的相关片段。手机支架项目为三维制作；两条 AI 叙事短片标为个人创作。账号数据来自此前提供的历史截图，不代表实时数据。经历日期与下载简历按提供的 `D:/2026AI作品集/孙晓伟简历.pdf` 整理。

## 已提供的交互

- 首页背景视频播放与暂停；减少动态效果偏好会阻止自动播放。
- 锚点导航、移动端菜单、项目分类筛选。
- 七个真实项目的视频弹窗、上一个/下一个、Esc 关闭与焦点返回，数量按项目内容自动统计。
- 大疆项目内的七段素材切换、Osmo 360 II 成片与白膜预演切换；每个视频按需加载。
- 拓竹 A1 八段视频及莲花汽车五段视频切换。
- 经历展开、简历下载、电话和邮箱复制、邮件联系链接。

后续更换作品时，将文件放入 `public/assets/` 并修改 `src/content.js` 对应的 `image`、`video`、`duration` 和职责说明即可。同一项目的多段素材放在项目的 `clips` 数组中；`title` 为片段名称，`stage` 为成片、白膜预演或 AI 生成等阶段。
